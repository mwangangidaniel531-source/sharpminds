SMART MINDS BLOG - PUBLISHING GUIDE

Files:
- index.html: blog content and page structure
- style.css: black-and-white styling
- script.js: mobile navigation, article search, and share button
- images/blog-hero.png: hero image

To preview:
1. Extract the ZIP.
2. Open the smart-minds-blog folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

To publish free with GitHub Pages:
1. Sign in to https://github.com/ and create a new public repository named smart-minds-blog.
2. Upload index.html, style.css, script.js, README.txt, and the images folder (keep the folder structure).
3. In the repository, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. Wait a few minutes. GitHub will show the website URL on the Pages settings screen.

Note: GitHub Pages publishes static websites. This blog does not yet have a comment system, server-side search, or a custom domain.
